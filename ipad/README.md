# EPC 単一HTML版（iPad / ブラウザ用）試作

Android版アプリ（v4.5）と同じUI・データを、単一のHTMLファイルに丸ごと
埋め込んだ試作版。ネット接続も画像パック取り込みも不要で、ファイル単体で
部品カタログを閲覧できる。

## 成果物

| ファイル | 内容 |
|---|---|
| `epc-city.html` | シティ収録版（16.8 MB）。カタログ 11SA702（CITY E-AA / CITY PRO L-VF / CITY TURBO）＋ 11SC701（CITY CABRIOLET E-FA） |
| `build_ipad.py` | 生成スクリプト。他カタログでも再利用可（下記） |

収録データ（DBと件数一致を検証済み）: モデル 59件 / 図 374件 /
部品 12,780件 / ホットスポット 9,746件 / 図画像 372枚（全て完全デコード
＋寸法一致を確認）。データ源はAndroid版と同じ DISC1（11CD081 / 2008-01）。

## iPadでの開き方

1. `epc-city.html` を iPad に転送する（AirDrop、メール、クラウド等）。
2. 「ファイル」Appに保存されるので、ファイルをタップする
   → Safari（またはHTMLビューア）で開く。
3. あとはAndroid版と同じ操作: 車種選択 → グループ目次 → ブロック →
   図ページ（タップで部品ハイライト、適合表示、絞り込み、買い物リスト、
   ☆お気に入り車種、🔖セクション登録＋☰ドロワー）。

※ 初回表示は16.8MBの読み込み・解析のため数秒かかることがある。
※ 「ファイル」Appのプレビューで開いた場合はスクリプトが動かないことが
ある。その場合は共有メニューから Safari で開くこと。

## 制約（Android版との違い）

- **収録カタログのみ**: 検索（部品番号/部品名）は収録カタログ内だけが対象。
  車種選択にも収録分しか出ない。
- **画像パック取り込みはなし**: 図は全て埋め込み済みのため不要。
- **買い物リスト等の保存**: localStorage を使う。file:// での保存可否は
  iPadOS / Safari の設定に依存し、環境によってはアプリを閉じると消える
  ことがある（その場合はメモリ内保持に自動で切り替わり、開いている間は
  使える）。Android版とのデータ互換はない（キー名は同じだが端末が別）。
- **戻るボタン**: 画面左上の「‹ 戻る」でアプリ内を戻る。最上位で押しても
  ブラウザは閉じない（Android版の終了動作に相当する処理はない）。
- 動作確認は生成データとJSの自動検証まで（実機 iPad での確認は未実施）。

## 仕組み

`build_ipad.py` が次を生成する（android側の資産は変更しない）:

1. `android/assets/epc_v4.db` から対象カタログ分を、Androidブリッジ
   （MainActivity.java）と同一のSQL・ロジックで抽出してJSON化
   （装備 tags = モデル ids の3番目以降 → equip名、部品 codes =
   gjson のグループ別コード列の和集合で再構成）。
2. 図PNGを `figures/<catalog>/...` から base64 で埋め込み。
3. `android/assets/index.html` のコピーに、ネイティブブリッジ
   `window.EPC` の JS シムを差し込み（`EPC.imgSrc()` が data URI を返す）。
   `home()` は収録車種のみ、`search()` は収録カタログ内のみに限定。

## 他カタログでの生成

```sh
cd ~/workspace/epc-project/ipad
python3 build_ipad.py --catalogs 11SD501,11SD511   # 例: トゥデイ JW1/JW2
# -> epc-11sd501_11sd511.html が生成される（--out で名前指定可）
```

生成後に自動で検証が走る（DBとの件数照合、PNGマジック、node による
JS構文チェック）。カタログを増やすほどファイルは大きくなる
（図画像が支配的。シティ2カタログで約16.8MB）。
